

# 🌲 Trrimber - AI/ML Powered Flutter App 📱  

Welcome to the **Log Stack Analyzer** repository! This Flutter-based mobile application leverages AI/ML to detect logs in a stack, allowing users to measure and analyze logs efficiently.

## 🌟 **Features**  

### 🤖 **AI-Powered Log Detection**  
- Uses an offline AI/ML model to detect and identify logs in an image.  
- Users can select or deselect detected logs manually.  

### 📏 **Log Measurement & Volume Calculation**  
- Set a reference diameter for accurate log measurements.  
- Calculates the average diameter and total volume of selected logs.  

### 📍 **Location-Based Features**  
- Uses the device's current location for accurate data recording.  

### 🔄 **Offline & Online Data Storage**  
- Stores data locally and syncs with an online database when connected.  

### 🔐 **Secure Authentication**  
- Sign up/login using Google and Apple authentication and 2 factor authentication.  

### 📄 **PDF Export & Sharing**  
- Users can generate a PDF report of log measurements and share it with others.
